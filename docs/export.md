# 怎麼匯出聊天紀錄

> 各 App 的選單名稱會隨版本調整，找不到時用關鍵字「匯出」「下載你的資訊」「聊天記錄」搜尋設定。
> 只匯出你自己參與的一對一聊天。

## LINE
手機：打開和對方的聊天室 → 右上角「≡」→ 設定（齒輪）→ **傳送聊天記錄** → 存成 .txt 檔（可以傳到自己的信箱或存到檔案 App）。
- 中文、英文、日文介面匯出的格式都支援。

## Instagram
設定 → **帳號管理中心** → 你的資訊和權限 → **下載你的資訊** → 選 Instagram 帳號 → 選「部分資訊」只勾**訊息** → 格式選 **JSON**、媒體品質選低 → 建立檔案。
幾小時到幾天後會收到通知，下載 zip 後解壓縮，在 `your_instagram_activity/messages/inbox/<對方名字>_數字/` 裡找到 `message_1.json`、`message_2.json`……整個資料夾丟給 parse.py 即可。

## Messenger
兩種都可以：
- **Facebook 下載你的資訊**：和 Instagram 一樣在帳號管理中心，選 Facebook、只勾**訊息**、格式 **JSON**。檔案在 `messages/inbox/<對方>/message_*.json`。
- **加密聊天的下載**：Messenger 設定 → 隱私與安全 → 端對端加密聊天 → 訊息儲存 → 下載安全儲存資料，會得到每個聊天一個 .json。

## WhatsApp
打開和對方的聊天 → 點上方對方名字 → 最下面 **匯出聊天** → 選**不含媒體** → 存成 .txt（或 zip，解壓縮後取裡面的 `_chat.txt`）。
- iPhone 和 Android 的格式都支援，日期是 日/月 或 月/日 會自動判斷。

## Telegram
需要電腦版 **Telegram Desktop**：打開和對方的聊天 → 右上角「⋮」→ **匯出聊天記錄** → 取消勾選照片等媒體 → 格式選 **機器可讀的 JSON** → 匯出，會得到 `result.json`。
- 也可以從 設定 → 進階 → 匯出 Telegram 資料 一次匯出全部，只會讀一對一聊天。
